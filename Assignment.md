# Abbey FullStack Engineer Challenge

## Description

---

For this particular challenge, we want to present a process that will be similar to your working process here at Abbey. Your task is to implement a full-stack application that contains the following:

- Authentication (Login/Logout, Session handling)
- Accounts (User ability to store and retrieve information specific to their account)
- Relationships (Connections between users of some form i.e. friends, followers, peers, etc.)

You are given a complete license in how you choose to implement this and what the application is for. You may host this application using any service you'd like. The expectation is not for this to be a production ready application but more-so an opportunity to see how you think through architectural problems. It is more important to have something functional from backend to frontend rather than having the latest libraries and overly complex code that is hard to read or debug, so please keep this in mind when completing your submission. Make it as simple as possible, while sticking to firm and consistent aesthetic choices.

---

For this challenge, you may take up to 3 days, but we would like for you to share the repo you're working on with us as soon as possible, preferably via Github. An important caveat to note, is that because we have a broad scope of implementations for this particular challenge, we are relying on you to create a functional implementation that is rather easy to get spun up.
